# Font Awesome Free icons (fa-*.svg / fa-*.png)

The `fa-*` icons are from Font Awesome Free 5.15.4
(https://fontawesome.com), licensed CC BY 4.0
(https://fontawesome.com/license/free). Each SVG retains the license
comment from upstream; the PNGs are rendered from those SVGs by render-fa.sh,
which applies fill colors from fa-colors.txt at render time. The SVGs are
unmodified upstream files.
